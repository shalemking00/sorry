# Sorry, My Love ❤️

## Run
```bash
npm install
npm run dev
```

## GitHub Pages
Create a repository such as `sorry-my-love`, push this project, then run:
```bash
npm install
npm run deploy
```
In GitHub: Settings → Pages → select the `gh-pages` branch.

Your URL:
`https://YOUR_USERNAME.github.io/sorry-my-love/`

## Personalize
Edit `src/main.jsx` to replace the apology, images, and music URL.
For a permanent site, use your own licensed/local image and audio files in `public/`.
